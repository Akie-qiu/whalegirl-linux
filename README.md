# 鲸鱼娘 Linux 轻量版

## 当前项目总览（2026-10-22）

全 Linux 微信群友机器人：固定微信 **4.1.1.8**，Python 回复核心、原生客户端适配与服务器常驻管理网页。当前完整功能、架构和已知限制见 [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md)。下文按时间保留早期部署记录，其中旧版本、旧参数、旧验收状态不代表当前配置。

- 自然聊天：连续消息缓冲、参与意愿、文字与原生表情穿插、自主引用、拍一拍、可调回复温度及文字后配表情。
- 图像和消息：当前会话上下文、引用/合并转发解析、图片及引用图来源绑定、完整收件记录。
- 记忆与关系：群事件分会话存储，明确个人偏好按真实微信 ID 跨会话调用；共享好感度，群聊保持朋友语气。
- 表情管理：语义标签复用、AI 自主收藏收到的原生表情、可恢复停用、保护与撤销，微信收藏保留。
- 管理与稳定性：模型和提示词、授权群及唤醒条件、发送额度、登录面板、故障暂停、服务器运行日志。

### 发送上限、表情偏好与管理密码

“发送上限”独立面板提供条数限制开关，以及账号每分钟、每小时、每天、单个会话每小时四项上限；各项填0表示不限制该项。关闭条数上限后，运行保护仍可继续处理重复回复、客户端警告与明确发送失败。“会话与唤醒”中增加表情包积极性：克制、适中、积极。该选项调整同一轮模型生成的原生表情选择偏好，不承诺固定发送比例。

手动登录使用独立管理密码，密码经过加盐派生后保存；登录后使用24小时有效的随机会话凭据，退出时撤销。SSH一键入口继续使用服务器私有维护凭据自动连接。本次密码更新同时轮换原维护凭据，旧网页需要刷新并重新登录。

### 本地运行保护

网页“运行保护”默认启用：账号最多8条/分钟、120条/小时、500条/北京时间自然日；单个会话最多40条/小时；180秒内相同回复不重复发送。按数据库已有自动发送记录计算，重启不清零。达到限额时跳过新回复，仍保存聊天上下文；窗口恢复后只处理新消息，不集中补发。

每30秒从微信系统提示框检查可见的异常、验证或功能限制提示，不把普通聊天中的“账号异常”等字样当成客户端警告。检测到相关提示、账号变化或连续3次明确发送失败时持久暂停，需在网页检查后人工恢复。10分钟内最多请求3次重新登录；已有登录不刷新。发送不确定仍保留原有人工核对机制，不自动重试。保护不会自动处理微信验证或关闭警告。

这些是本地防刷屏与故障保护，不是微信公布的安全阈值；无法读取平台内部风控分，也不能保证不限制账号。保护设置、当前计数、检查错误和事件记录均在网页中显示。

### 自主引用回复

“会话与唤醒”中的“AI 自主选择引用回复”默认开启。AI 在同一轮回复生成中选择是否引用，以及需要回答的近期文字消息；多人交错聊天或回答较早的问题时可原生引用，连续闲聊通常直接回复。不会额外增加一轮模型调用。原生收藏表情仍独立发送。

原生引用由微信右键菜单的 Quote 动作完成，并通过新发消息内的引用源服务端 ID 读回验证。目标不在当前可见近期消息中或无法定位时，改为普通文字回复，不反复滚动寻找。2026-10-20 已在“临时测试”验收真实原生引用，证据位于服务器 `quote-replies-acceptance.json`；3.427 秒仅为发送和读回阶段，不是完整 AI 回复耗时。

双击本目录的 `微信机器人控制台.lnk`，或用 PowerShell 运行 `打开微信机器人控制台.ps1`。入口会建立到 Linux 服务器的 SSH 加密隧道并自动登录控制台，网址为 `http://127.0.0.1:18092/`。直接打开本地 `web.html` 会跳转到此入口；隧道未建立时需先运行脚本。

网页支持掉线扫码/手机确认登录、系统提示词编辑和恢复内置人设、各群回复开关与“自然接话 / 仅唤醒回复”、关键词、模型接口与密钥、上下文和共享记忆、回复节奏、处理记录和不确定发送的人工核对。提示词保存到服务器配置，下一次回复生效，无需重启微信。管理页面与 API 均通过现有访问密钥认证；网页本身只在服务器回环地址监听。

当前部署固定使用 **Linux WeChat 4.1.1.8**，容器为 `whalegirl-wechat-candidate-4118`。下文 4.1.0.16 的拒绝登录记录属于早期尝试。私聊和两个授权群的自动回复已启用。2026-10-20 后续修复中，最新一条实际自动回复从入站至确认 **5.391 秒**；单独文字发送至读回 **2.007 秒**，两者范围不同，不能当作稳定延迟保证。

- 文字私聊和指定群；群聊可要求 @ 或关键词。
- 人设与有限历史上下文、连续消息合并、去重、全局发送间隔。

- 首次读取建立历史基线；自己发出的消息不触发回复。启用视觉时，授权私聊中的新图片可触发回复。

### 自然接话、拍一拍与原生表情（2026-10-20 后续修复）

- 已授权的两个群开启 `natural_group_replies`，普通消息先由同一次生成判断是否适合参与；明确 @、关键词、私聊和针对机器人的拍一拍直接触发。旁观时不发消息。已实际确认无 @ 的群消息产生自动回复。
- 从原生 type 49 / appmsg 62 的 `patinfo` 读取真实发起者和目标，针对本账号的拍一拍进入回复队列，不误响应其他人互拍。已核对现场拍一拍数据及入队；停机期间过期的旧消息不补发。
- `sticker-catalog.json` 持久保存「MD5 → 含义」。AI 在结构化回复中选固定 ID，调用 `AgentGateway.send_sticker()`。发送通过原生 Custom Stickers 面板，读回须同时满足本人、新消息、type 47、MD5 一致。已现场验证害羞表情的确切 MD5；粘贴 GIF 产生的 type 3 图片不算表情验收成功。
- 新收藏自动增量索引，每批最多五个，只对未标注表情调用一次视觉模型，成功标签持久保存。读取与发送已知表情复用标签，不逐条重新识图。缺失素材退避重试，不阻塞聊天。接口为 `GET /api/stickers`、`POST /api/stickers/refresh`，均沿用管理认证。

### 当前上下文、全局记忆与图片能力（2026-10-20）

- 三个已授权会话会分页归档 Linux 客户端本地可读取的历史消息，包括未 @ 的群消息、自己发出的消息及系统消息；不代表能取得手机端尚未同步到 Linux 的所有历史。
- 每次回复附带当前会话最近 60 条消息，并从持久归档检索相关的跨会话历史。用户明确授权两个群与“飘·渺”私聊的记忆全部互通；资料保留原始来源和说话人，不依赖模型凭空总结。
- 图片消息先尝试图像缓存；4.1.1.8 缺少匹配的图片密钥配置时，按原始 localId 与原生消息行对应，打开目标图片预览并复制实际 PNG。已实测读取私聊第 31 条图片的 **1272×2800 原图**，正确识别“沃不明白”聊天截图。原图复制不可用时才裁取目标消息的可见缩略图，并明确清晰度和裁切限制。不是 OCR，也不改变微信协议。
- 图像直接随本次回复发给当前 DeepSeek 模型，不额外串行调用另一套视觉模型；成功的图像描述与图像缓存持久保存，后续可作为记忆使用。群内普通图片先作为上下文，仍由 @ 或关键词触发回复；私聊图片可直接触发。

### 原生批量 UI 适配

当前后续镜像为 `whalegirl-wechat:4.1.1.8-fastui-20261020`，仍固定同一微信版本。核心通过独立的 `whalegirl-jobs` 私有目录提交一次性任务，借助原有 chat-open 计划进入上游 GUI guard，在同一受控操作内确认会话、聚焦、粘贴并按一次 Return；以实际本机消息记录确认发送。任务创建 claim 后不会重复执行，历史任务保留而不自动删除。

图片以明确的原生 localId 与当前消息行对应。当前触发消息是图片时，只附带该条图片，不用上一张图片替代。能打开原生图片预览时，尝试通过预览的复制功能读取实际 PNG；否则裁取已确认位置的可见图片并去除行背景。可见截图仍可能存在清晰度或裁切限制，模型必须说明无法辨认的细节。

### 实时消息读取与当前部署复现

旧网关通过 `immutable=1` 读取原生数据库，消息写入 WAL 后到主数据库可见之间出现约十秒延迟。新增 `deploy/native_message_reader.py`，仅对三个授权会话，以 SQLCipher 的 `-readonly`、`mode=ro` 和 `query_only=ON` 读取已提交消息，包含 WAL；不向微信数据库写入或执行 checkpoint。凭据留在容器内部，核心通过私有 Unix socket 读取，不新开公网端口。实时读取不可用时仍回退原网关。

`whalegirl-native-reader.service` 在主机启动 `deploy/start_native_reader.py`，把 `/data/native-tools/chat_select_linux.py` 挂载到正在运行的容器工具路径，再启动只读服务。脚本和授权配置位于主机 `/var/lib/whalegirl-linux/candidate-4.1.1.8/gateway/native-tools`，属于 root；socket 与一次性 UI 任务位于 `gateway/whalegirl-jobs`。核心通过 `40-fast-ui.conf` 中的 `WHALEGIRL_UI_JOBS_DIR` 使用这两个接口。重新创建容器后应启动该辅助服务；它会恢复工具挂载，不要求重启已有微信会话。

当前验收报告位于服务器 `context-vision-speed/current-image-acceptance.json` 和 `context-vision-speed/fast-live-send-acceptance.json`；前者保留原图识别结果及早期约 12 秒的发送读回，后者记录实时消息读取上线后的两个群实发耗时。两者不能混同为同一轮全流程延迟。
